# A Video and Its Sound in One Row, Images in the Sequence — Implementation Plan

> **For the implementing agent:** work task by task, in order. Steps use checkbox
> (`- [ ]`) syntax — tick them as you go. Do not skip the "run it and see it fail"
> steps. If a step's expected output doesn't match, stop and report; don't improvise
> a different design.

**Goal:** A video added with sound gets one timeline row (its sound "tucked" inside);
right-click shows/hides the sound's own row; while tucked, every edit of the video is
repeated on the sound; images are 3 s and join the play-one-after-another sequence.

**Architecture:** The sound stays an ordinary audio layer, so preview, export, merge
and subtitles don't change. Two new fields on the audio kind link it to its video and
mark it tucked. A new Rust module `linked_sound.rs` holds every follow rule as small
pure functions; the existing Tauri commands call them, so the timeline, menus and the
AI assistant all get the same behaviour in the same undo step. The frontend only hides
tucked rows, draws their waveform inside the video block, and adds the menu items.

**Tech Stack:** Tauri 2.11 (Rust), ts-rs 12 (bindings), React + TypeScript, Vite, vitest.

**Spec:** `docs/superpowers/specs/2026-11-17-video-sound-one-row-design.md` — read it
first; its edit table is the contract for Tasks 2–4.
